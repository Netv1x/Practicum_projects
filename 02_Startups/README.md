# Исследование стартапов и инвестиций (Яндекс Практикум, июнь 2026)

## Задача
Провести предобработку исторических данных о стартапах и исследовать динамику венчурного финансирования, чтобы дать инвестиционной компании рекомендации по выходу на рынок с позиции 2015 года.

## Инструменты
*   **Python (Jupyter Notebook):** pandas, matplotlib, seaborn.
*   **Методы:** предобработка данных (очистка типов, заполнение пропусков), поиск выбросов (метод IQR по сегментам), исследовательский анализ данных (EDA), когортный анализ (динамика по годам).

## Ключевые результаты и инсайты
*   **Структура финансирования:** Единичное финансирование преобладает по числу компаний (58,9%), однако по объему привлеченных средств лидируют проекты со сроком финансирования более года (61,9% инвестиций).
*   **Динамика рынка:** Пик типичного размера раунда пришелся на 2005 год ($4,5 млн). В 2014 году активность на рынке упала на 43% по сравнению с 2013 годом, а средний чек раунда стабилизировался на уровне $600 тыс.
*   **Возврат инвестиций:** Наиболее высокую и устойчивую долю возврата показывают зрелые типы финансирования: `private_equity` (113,7%) и `debt_financing` (83,1%). При этом популярные `seed` и `venture` возвращают лишь 25% и 38,8% соответственно, что говорит о более высоких рисках.
*   **Рекомендация:** Наиболее перспективными для инвестирования признаны массовые сегменты Technology, Cloud Computing, Internet и Startups. Для минимизации рисков рекомендовано использовать инструменты `private_equity` и `debt_financing`.
